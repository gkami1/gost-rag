# Реестр документов

`documents.csv` — список документов корпуса. Сами PDF в репозиторий не входят
(см. раздел «Корпус» в README), поэтому реестр — единственный способ понять,
из чего собран индекс, и воспроизвести его у себя.

Колонки:

| Колонка | Обязательна | Описание |
|---|---|---|
| `designation` | да | Обозначение ровно в том виде, как в документе: `ГОСТ 14634-93` |
| `title` | нет | Наименование стандарта |
| `year` | нет | Год редакции (4 цифры) |
| `status` | да | `действующий`, `отменён`, `заменён` (можно без «ё») |
| `source_url` | нет | Откуда взят файл |
| `replaced_by` | нет | Обозначение действующей замены |

Статус нельзя вывести из текста самого стандарта — в нём не написано, что его
отменили. Поэтому он берётся отсюда и показывается рядом с каждой цитатой:
ответ по отменённому стандарту хуже, чем отсутствие ответа.
